Введение в Control D

Control D — это настраиваемый DNS-резолвер и платформа фильтрации трафика, которая позволяет управлять интернет-соединением на уровне DNS-запросов. В отличие от обычных DNS-серверов, Control D дает гранулярный контроль над тем, какие домены разрешаются, блокируются или перенаправляются.

💡 Ключевая идея

Control D — это DNS-сервис, который можно настроить под свои нужды: блокировать рекламу, защищать от вредоносных сайтов, перенаправлять трафик через прокси в 100+ локациях.

Что такое DNS?

DNS (Domain Name System) — это система, которая преобразует человекочитаемые доменные имена (например, google.com) в IP-адреса (например, 142.250.80.46). Работает как телефонная книга интернета:

Этап Описание
Запрос пользователя Вводите example.com в браузере
DNS-резолвер Ваше устройство отправляет запрос к DNS-серверу
Обработка DNS-провайдер обрабатывает запрос (ISP, Google, Cloudflare, Control D)
Ответ Возвращается IP-адрес запрашиваемого домена

Как работает Control D?

Control D предоставляет уникальные DNS-резолверы, которые могут манипулировать ответами на основе заданных правил:

1️⃣ Резолюция

По умолчанию Control D работает как обычный DNS-резолвер — разрешает домены в IP-адреса.

2️⃣ Правила

Когда вы настраиваете фильтры, сервисы и кастомные правила, Control D начинает перехватывать DNS-запросы.

3️⃣ Действия

Для каждого запроса применяется одно из действий: BYPASS, BLOCK или REDIRECT.

Основные компоненты

Профили (Profiles)

Профиль — это набор правил и настроек, которые применяются к Endpoint. Каждый профиль содержит фильтры, правила для сервисов, кастомные правила и опции поведения.

ℹ️ Множественные профили

Можно создавать десятки профилей для разных сценариев: рабочий (блокировка отвлекающих сайтов), детский (безопасный поиск), персональный (свои правила).

Фильтры (Filters)

Фильтры — это готовые списки блокировки, которые обновляются каждые 15 минут:

Фильтр Описание Режимы
Ads & Trackers Реклама и трекеры Minimal / Balanced / Aggressive
Malware Вредоносные домены Relaxed / Balanced / Aggressive
Phishing Фишинговые сайты —
Social Социальные сети —
Typo Squatting Защита от тайпсквоттинга —
IoT Telemetry Телеметрия IoT-устройств —

Сервисы (Services)

Сервисы — это готовые коллекции доменов, принадлежащих конкретному сайту или приложению. Например, сервис facebook включает десятки доменов: facebook.com, fbcdn.net, instagram.com.

Для каждого сервиса можно задать одно из трех действий:

Действие Код Описание
BYPASS 0 Разрешить, использовать реальный IP
BLOCK 1 Заблокировать полностью
REDIRECT 3 Перенаправить через прокси (указать локацию)
✅ Более 400 сервисов

Control D поддерживает 400+ сервисов: от Amazon и Netflix до специфических банковских сервисов. Сервисные правила имеют приоритет над фильтрами.

Приоритет правил

При совпадении нескольких правил для одного домена применяется правило с наивысшим приоритетом:

Приоритет Тип правила Описание
1 (выше всех) Custom Rules Гранулярные правила для конкретных доменов
2 Services Правила для сервисов (400+ готовых)
3 Filters Категориальные фильтры
4 Geo Custom Rules Гео-логика
5 Default Rule Правило по умолчанию (ловушка)

Настройка и развертывание

DNS-протоколы

Control D поддерживает различные DNS-протоколы для безопасной передачи запросов:

Протокол Порт Безопасность Поддержка
Legacy DNS (UDP 53) 53 Низкая Все устройства
DNS-over-HTTPS (DoH) 443 Высокая Современные ОС
DNS-over-TLS (DoT) 853 Высокая Современные ОС
DNS-over-QUIC (DoQ) 853/QUIC Высокая Экспериментальный
⚠️ Рекомендация

Используйте DoH или DoT для шифрования DNS-запросов. Legacy DNS не шифруется и может быть перехвачен или подменен провайдером.

Профили для Нью-Йорка

Философия JFK-профиля

JFK-профиль создает иллюзию нахождения в Нью-Йорке (JFK — код аэропорта). Основной принцип: весь трафик идет через JFK, кроме явно прописанных исключений.

🌍 Гео-маскировка

Ваш IP адрес выглядит так, как будто вы находитесь в Нью-Йорке (East Coast USA)

🔒 Приватность

Реальный IP скрывается за прокси-сервером. Сайты видят только JFK IP

⚡ Скорость

Оптимизированные маршруты через Windscribe инфраструктуру в Нью-Йорке

🛡️ Безопасность

Встроенная фильтрация: малвер, реклама, трекеры, IoT телеметрия
